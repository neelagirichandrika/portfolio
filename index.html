Shortest Path & Priority Dispatching

When optimizing vehicle routing in FleetTrack, I modeled city junctions as graph nodes with weighted edges representing live travel latency.

1
Adjacency Representation: Using an adjacency list with HashMap<Integer, List<Edge>> ensures O(V + E) space efficiency over dense matrix waste.
2
Min-Heap Extraction: PriorityQueue<NodeDistance> continuously picks the closest unvisited node in O(log V) time.
3
Edge Relaxation: Updating tentative shortest paths only when a strictly superior path is verified.
Time: O((V + E) log V) · Space: O(V)
Path resolved: Hub (A) → Transit (D) → Dest (C) [Optimal: 14 mins]

Encapsulated Domain Contracts

In object-oriented design, I believe objects should guard their own invariants. A vehicle cannot be assigned to two routes simultaneously, and mileage cannot decrease.

VehicleDispatch.java 
public class FleetVehicle {
    private final String vehicleId;
    private VehicleState state;
    private double currentCapacity;

    public synchronized boolean assignRoute(Route targetRoute) {
        if (this.state != VehicleState.AVAILABLE) {
            return false; // Invariant preserved
        }
        this.state = VehicleState.DISPATCHED;
        return true;
    }
}

Maximum Flow & Bottleneck Resolution

Understanding network capacity through Ford-Fulkerson and Edmonds-Karp. By continuously finding augmenting paths using BFS and computing residual capacities, we determine the exact throughput ceiling of any network.

  • Residual Graph: Tracking forward capacity remaining and reverse flow cancellation.
  • Min-Cut Max-Flow Theorem: Proves that the maximum flow through a network equals the minimum capacity cut separating source from sink.
Source Node: S
Sink Node: T

01
Java + DSA Systems Architecture

FleetTrack

Fleet management and dynamic route optimization system.

🎯 WHY I BUILT IT

I wanted to take graph theory out of textbook exercises and apply it to a realistic logistics challenge: managing multiple transit vehicles with fluctuating traffic delays and delivery constraints without relying on external black-box mapping libraries.

🛠 WHAT I WORKED ON

Modeled road topologies as weighted adjacency lists, implemented Dijkstra's algorithm with priority queues for real-time shortest paths, developed thread-safe vehicle state monitors, and structured clean OOP domain models with separation of dispatch logic.

💡 WHAT I LEARNED

How dynamic edge weights complicate caching; why clean object boundaries make rerouting algorithms testable; and how to optimize memory usage by choosing primitive-backed collections where applicable.

Technologies: Java Object-Oriented Programming Graph Algorithms PriorityQueue & Heaps Custom Collections

02
Python + ML + FastAPI Fraud Risk Detection

RiskShield-X

Fraud risk detection based on transaction behavior and user activity patterns.

🎯 WHY I BUILT IT

Financial fraud presents severe class imbalance: less than 0.2% of transactions are malicious. I wanted to understand how machine learning models detect subtle behavioral anomalies without overwhelming operations with false positives.

🛠 WHAT I WORKED ON

Extracted temporal behavioral features (velocity of transactions, geo-ip distance deltas, sudden spending spikes), trained supervised classification and anomaly scoring models in Scikit-learn, exposed real-time inference via FastAPI endpoints, and built an audit dashboard using Streamlit.

💡 WHAT I LEARNED

Standard accuracy is a deceptive metric on imbalanced data—Precision, Recall, and PR-AUC dictate business utility. Also learned how serialize models cleanly and manage API request validation schemas.

Technologies: Python Scikit-learn FastAPI Streamlit Pandas REST APIs

Python + ML + Scikit-Learn Healthcare Analytics

Diabetes Hospital Readmission Prediction

Hospital readmission classification using a large healthcare dataset.

🎯 WHY I BUILT IT

Healthcare data is notoriously dirty, high-dimensional, and full of missing records. I wanted hands-on experience navigating the challenges of real patient records to predict whether a diabetic patient would be readmitted within 30 days.

🛠 WHAT I WORKED ON

Conducted extensive exploratory data analysis on 100,000+ patient records, imputed missing laboratory measurements, encoded medical diagnosis ICD-9 categories, engineered features for medication changes and prior emergency visits, and trained comparative classifiers.

💡 WHAT I LEARNED

Data preprocessing and clinical domain feature creation have a far bigger impact on outcome than algorithm tuning alone. Also gained deep respect for ethical model calibration in healthcare applications.

Technologies: Python Pandas NumPy Scikit-learn Matplotlib Streamlit
